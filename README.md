# NMAP-Password-cracking-assignment

 OverviewThis repository contains my individual lab documentation for the ParoCyber Ethical Hacking Program. It covers hands-on practical work in network scanning, service enumeration, vulnerability detection, and password cracking  all performed in a controlled, isolated virtual lab environment.Every lab was conducted legally on systems I own and configured specifically for this course. The target machine used throughout is Metasploitable 2, an intentionally vulnerable virtual machine designed for security training.
